\begin{frame}{Normalisation des données}

    \begin{definitionbox}
        La \textbf{normalisation} est un processus de structuration des données
        pour :
        \begin{itemize}
            \item éliminer les redondances
            \item organiser les données efficacement
            \item réduire les potentielles anomalies lors de leur manipulation
        \end{itemize}
    \end{definitionbox}

    \vspace{0.7cm}
    \pause

    L'objectif principal est de garantir qu'\textbf{aucune irrégularité sur les
    transactions} de lecture, d'écriture ou d'insertion n'influence la
    performance et la capacité de maintenance du système.

\end{frame}

\begin{frame}{Comment normaliser ?}

    La normalisation consiste en des méthodes de décomposition de relations en
    plusieurs relations plus petites, appelées formes normales.

    \vspace{0.3 cm}

    \begin{columns}[onlytextwidth]% align columns
        \begin{column}{.52\textwidth}
            En informatique, une \textbf{forme normale} est un ensemble de
            règles visant à organiser les données dans une base de données
            relationnelle afin de minimiser la redondance et d'améliorer
            l'intégrité des données.
        \end{column}%
        \hfill%
        \begin{column}{.44\textwidth}
            \begin{figure}[htb]
                \centering
                \resizebox{0.8\textwidth}{!}{
                    \begin{tikzpicture}[circle type 1/.style={draw=none,align=center,
                            font=\scriptsize,text width = 2cm},]

                        \coordinate (c1) at (0,0);
                        \newlength{\smallercircle}

                        \foreach \i / \j [count=\ino] in
                        {5cm/5FN, 4.2cm/4FN, 3.4cm/FNBC, 2.6cm/3FN, 1.8cm/2FN,
                            0.9cm/1FN}
                        {
                            \pgfmathsetmacro{\colmixer}{mod(10*\ino,100)}%
                            \path [fill=disco!\colmixer] (c1) ++(0,-\i) arc
                            (270:-90:\i);
                            \ifnum\ino<7
                            \setlength{\smallercircle}{\i}
                            \addtolength{\smallercircle}{-7.5pt}
                            \path [decoration={text along path, text={\j}, text
                                    align=center, reverse path},
                                decorate] (c1) ++(0,-\smallercircle) arc (-90:270:\smallercircle);
                            \fi
                        }
                    \end{tikzpicture}
                }
            \end{figure}
        \end{column}%
    \end{columns}

    \note{
        Il existe 8 formes normales. En pratique on s'arrête à la 3FN.

        Chaque nouvelle forme normale marque une étape supplémentaire dans la
        progression vers des relations présentant de moins en moins de
        redondance et d'anomalies.
    }

\end{frame}
